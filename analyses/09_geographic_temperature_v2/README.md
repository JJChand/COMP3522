# 09 v2 — Geographic representativeness of a general Hong Kong forecast

Latest submitted version: [general_forecast/README.md](general_forecast/README.md).

The 2025 retrospective analysis treats the nine-day product as a common Hong Kong forecast, without assuming a Tsim Sha Tsui target, a spatial average, or a territory-wide extrema envelope. No offset is applied. Tmax/Tmin and RHmin/RHmax are evaluated separately using same-day station pairs and the same revision events within each geographic contrast.
